# Lyndbaum0

adiaryをリスペクトして作ったブログ向けCMS。

実運用が可能なレベルまで開発したが、adiaryにパフォーマンスで勝てず、adiary独自機能を取り込むのも限界があったため、開発を中断する。

[様々な学びがあった](https://blog.lycolia.info/0805)ため、ここで開発した機能はadiaryのフォークであるadiary-Extendsもとい、[Lyndbaum](https://github.com/Lycolia/lyndbaum)にバックポートし、精神的後継として引き継ぐ。本システムはLyndbaumの始祖としてLyndbaumからLyndbaum0へ改称しアーカイブする。
